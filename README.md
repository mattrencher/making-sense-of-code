# Making Sense of Code

Workshop materials for **AI-Assisted Software Development**, a three-session introduction to using AI coding assistants thoughtfully and safely. The workshop is designed for university professionals and students across roles and disciplines. No programming background, VS Code installation, or active Copilot account is required to participate in the presentations.

The central idea is that AI can help explain, draft, or improve code, but its output is a starting point. People remain responsible for protecting sensitive information, checking suggestions, and understanding changes before using them.

## Workshop sessions

Each session is designed for approximately 45–60 minutes and uses prepared examples, presentation, and discussion.

| Session | Topic                                                     | What participants explore                                                                                                                       |
| ------- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 1       | AI coding tools: landscape, risks, and code comprehension | How coding assistants work, safe-use considerations, and how to verify an AI explanation of unfamiliar code.                                    |
| 2       | Prompting for code generation                             | How to turn a plain-language task into a clear prompt, compare generated code with the requirements, and identify what to validate.             |
| 3       | Refactoring and safe validation                           | How to request bounded changes to existing code, preserve intended behavior, and review changes for correctness, security, and maintainability. |

The sessions build on one another: understand and verify code, generate a draft from a clear requirement, then modify existing code carefully.

## Facilitator and participant notes

- The sessions are designed around prepared examples and discussion. Participants do not need to run Copilot or complete live coding exercises during the presentations.
- Use sanitized code and sample data only. Do not put passwords, API keys, personal information, student or employee records, or confidential institutional material into AI prompts or examples.
- Follow applicable institutional and IT policies for AI tools and data handling.
- Treat generated code and explanations as drafts. Check claims against the source, compare code with the original requirement or behavior, and test relevant examples before relying on it.
- Optional practice can be done after the workshop with Copilot access and non-sensitive examples.
